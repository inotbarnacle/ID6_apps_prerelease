2. Identify and install

Where do I find the version on iDrive?

Open Navigation → press OPTIONS → Navigation settings → Position and version → Version information. The full code starts with NBTevo_. Menu wording can vary.

iDrive display resolution

Choose the resolution iDrive sends to the display. This can differ from the panel’s advertised resolution. The inch size alone does not identify the layout.

The installer fills this in when Check compatibility reaches the head unit over SSH. Confirm the SSH IP belongs to your connected car and compare the fingerprint with a trusted copy if you have one. Then choose Trust this fingerprint and check.

Keep iDrive on and ENET connected during installation. Restart iDrive once the status says Installed and verified all three apps.
