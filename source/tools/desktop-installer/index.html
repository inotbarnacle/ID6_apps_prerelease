ID6Apps Installer

Park the car and wake iDrive. Enable temporary SSH with Bavarian SSH Client before continuing.

Menus to install

HUD Gauges is enabled per iDrive session. The overlay is unavailable when native Android Auto or a supported CarPlay HUD add-on is installed.

Menus to uninstall

Set any desired vehicle settings in iDrive before removing their controls. Selected menus are moved to a backup on the head unit.

CarPlay Advanced by st1ng

Adds CarPlay turn-by-turn directions to a compatible cluster or HUD. It downloads and verifies st1ng’s v1.3.0 release and uses its HUD-only installer. It backs up the original boot script, adds a boot hook and leaves iDrive running until you restart it. Wired ENET, working factory CarPlay and internet access are required.

Native Android Auto and CarPlay Advanced can compete for the same cluster and HUD. Upstream project and rollback instructions.
